# SIT772: Database Fundamentals

**Unit:** Database Fundamentals, Deakin University
**Type:** Individual database design and SQL tasks

> **Note:** This folder contains a write-up only. In line with Deakin University's academic integrity rules, I have not published assessment code or solutions. I'm happy to walk through the work in an interview.

## Overview
Data modelling through to working database-backed applications.

## What I did
- **Modelling:** identified entities, relationships and attributes from scenarios and drew **ER diagrams**, normalised to **3NF**.
- **SQL:** DDL and DML, JOINs, subqueries, views and triggers on **MySQL** and **SQLite**.
- **Integration:** connected databases to **PHP** web forms.
- **Procedural SQL:** **PL/SQL** procedures, functions and triggers.
- **Wider context:** business intelligence, big data principles and NoSQL, and how data is secured and used.

## Skills shown
Relational design, SQL development, and linking databases to applications. This is the same foundation I use when writing test queries and checking data as a QA engineer.

**Tools:** MySQL, SQLite, PHP, PL/SQL.
