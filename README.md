# Deakin MIT Projects

Cloud, DevOps and software engineering projects from my **Master of Information Technology (Networking & Cloud Technologies)** at Deakin University, Melbourne (completed October 2026).

I'm a QA and test automation engineer moving toward cloud and DevOps roles. These write-ups show what I built, the problems I hit, and how I solved them. Each folder explains the problem, my approach, the tools, and the result, so you can judge the work without opening any code.

> Assessment code and solutions are deliberately **not** published here, to respect Deakin's academic integrity policy. Each folder is a write-up of my own work. My team project SkillLink (SIT725) already has its own repository, linked below.
