# SIT774: Web Technologies and Development

**Unit:** Web Technologies and Development, Deakin University
**Type:** Weekly individual projects

> **Note:** This folder contains a write-up only. In line with Deakin University's academic integrity rules, I have not published assessment code or solutions. I'm happy to walk through the work in an interview.

## Overview
A progression from static pages to full dynamic web applications.

## What I built and learned
- **Front end:** semantic HTML, CSS and **Bootstrap** for responsive layouts, and **JavaScript** for interactivity.
- **Forms:** how browsers send POST data to the server and how to validate it.
- **Back end:** **Node.js** and **Express** with routing, middleware and error handling.
- **Dynamic pages:** **EJS** templates showing live data.
- **Persistence:** user contributions stored in an **SQLite** database.
- **Habits:** clean file structure, organised testing, and tracing data between client and server when debugging form and template problems.

## Skills shown
Full-stack JavaScript development and debugging.

**Tools:** HTML, CSS, Bootstrap, JavaScript, Node.js, Express, EJS, SQLite.
