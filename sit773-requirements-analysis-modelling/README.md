# SIT773: Software Requirements Analysis and Modelling

**Unit:** Software Requirements Analysis and Modelling, Deakin University
**Type:** Individual analysis tasks and case studies

> **Note:** This folder contains a write-up only. In line with Deakin University's academic integrity rules, I have not published assessment code or solutions. I'm happy to walk through the work in an interview.

## Overview
How to find, record and model what a system needs to do, and link software to business goals.

## What I did
- Wrote **problem and vision statements** and gathered requirements.
- Modelled with **use cases, wireframes and class diagrams**.
- Worked through case studies, including **Leckie's Choice**, to show how requirements are found and described.
- Carried out **feasibility analysis** and lifecycle-based planning.

## Why it matters for QA
Clear requirements are the base for good test cases. This unit strengthened how I trace tests back to requirements.
